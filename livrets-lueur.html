Codes de l’atelier : dans Étincelle (Plus, Gérer les familles), créez un code de groupe par atelier avec le seul pétale vécu, puis collez-le ici. Le QR ouvre l’app sans rien saisir. Ces champs ne sont pas imprimés.

Un ou plusieurs codes sont vides : la page « Pour mon parent » du pétale concerné affiche « code à saisir » à la place du QR.

28 pages A5 : chaque livret (4 pages) tient sur une feuille A4 pliée. Imprimez uniquement les pétales dont vous avez saisi le code (choisissez les pages dans la fenêtre d’impression).
